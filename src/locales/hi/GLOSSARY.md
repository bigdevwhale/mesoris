# Глоссарий хинди для проекта «Dinosaurs»

Этот глоссарь — авторитетный источник для всех хинди-переводов в проекте. Применяется ко всем UI-строкам, профилям динозавров, статьям, мифам, эрам, квиз-вопросам, играм и personality-разделу.

## Соглашения

1. **Транслитерация, не перевод.** Родовые имена динозавров транслитерируются в Devanagari. Например: `Tyrannosaurus rex → टायरानोसॉरस रेक्स`. Это стандарт NCERT и хинди-Википедии.
2. **Двойное упоминание.** При первом упоминании динозавра в длинном тексте добавляется оригинал в скобках: `टायरानोसॉरस रेक्स (Tyrannosaurus rex)`. Далее используется только транслитерированная форма.
3. **Этимология** в поле `nameMeaning` записывается в « » кавычках (хинди guillemets): `«भुजा-छिपकली»` — калька латинского названия. Само латинское имя — вне кавычек, через пробел.
4. **Международные термины.** Музеи, географические места, имена собственные остаются в оригинале: `Natural History Museum (London)`, `Cretaceous → क्रेटेशस` (транслитерируется).
5. **Числительные.** Хинди не имеет грамматического множественного числа для большинства существительных, поэтому «5 डायनासोर» остаётся «5 डायनासोर».
6. **Санскритские заимствования** для научных терминов. Например, `जीवाश्म` (jīvāśma, «след жизни») — стандартный хинди термин для «fossil».

## Стилистические правила для длинных текстов

1. **Длина предложений** — держать в пределах ±15% от английского, чтобы не сломать вёрстку.
2. **Детский стиль** — использовать `« » ` кавычки для выделения, простые слова, восклицания (`वाह!`, `अद्भुत!`).
3. **Научный стиль** — пассивные конструкции, точная терминология.
4. **Этимологии** — переводить дословно, не калькировать. Например, `Tyrannosaurus = "tyrant lizard" → «तानाशाह छिपकली»` (तानाशाह = tyrant, छिपकली = lizard). Аналогично для других греческих/латинских корней.
5. **Названия геологических формаций** — оставлять латинскими/английскими в скобках при первом упоминании.
